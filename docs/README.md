# Documentação de orientação do produto

Este diretório reúne o arcabouço inicial de orientação para o LifeInternet Mail Studio.

## Conteúdos

## Objetivo

Criar uma base útil para uso, onboarding e adoção da ferramenta, reforçando os fluxos de evento, público, template, SMTP e campanhas.

## Como usar

1. Comece pelo guia de uso para aprender o fluxo principal.
2. Depois, consulte o onboarding para mejorar a experiência do utilizador.
3. Use a documentação como base para apresentações, formação ou documentação interna.
